# Ziiom Video Editor Mobile

Versión Android nativa del editor Ziiom.

## MVP Android

- Importación de múltiples videos desde el teléfono.
- Vista previa con Media3 ExoPlayer.
- Línea de tiempo por clips.
- Búsqueda temporal y reproducción/pausa.
- Recorte de inicio y final por clip.
- Velocidad 0.5x–2x.
- Volumen por clip.
- Rotación 0/90/180/270 grados.
- Música de fondo opcional.
- Eliminación y selección de clips.
- Exportación de la secuencia completa como MP4 H.264/AAC.
- Guardado automático del resultado en Galería (Android 10+).

La app usa Jetpack Media3 Transformer para la exportación y ExoPlayer para la vista previa.
